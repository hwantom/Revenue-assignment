# BridgeOn Bank — Global Revenue Intelligence

글로벌 금융서비스 거래전표 100건 자동 정제 및 수익 분석 대시보드
목56 AI 데이터 자동화 · 5주차 프로젝트 · 202101308 민승환

`dashboard.html` 을 브라우저로 열면 됩니다. 데이터·세계지도·국기·Pretendard 글꼴(사용 글자만 남긴 부분 글꼴)이 HTML 안에 들어 있으므로 인터넷이나 로컬 서버 없이 `file://` 에서도 동작합니다. 차트와 지도는 외부 라이브러리 없이 SVG로 그립니다.

> **데이터 원칙** — 거래전표 100건은 실제 고객정보가 없는 시뮬레이션(Synthetic) 데이터입니다. 수수료는 시중은행 공개 수수료 구조를 참고한 BridgeOn 가상 정책입니다.
> **환율은 아직 시뮬레이션 기준값입니다.** 이 작업 환경에서는 한국은행 ECOS 에 접속할 수 없어 실제 환율을 받지 못했습니다. 아래 “실제 ECOS 환율로 교체” 절차를 실행하면 실제 고시 환율로 바뀌고, 대시보드의 출처 표시도 함께 바뀝니다.

## 처리 흐름과 검산 결과

```
원본 파일 103개 (TXT 22 · JSON 41 · CSV 40)
 → 형식 감지 3종 → 재전송 중복 3개 제거 → 100건
 → 사전 기반 표준화 + 오탈자 교정 (값 변경 기록 625건)
 → 거래일 환율 결합 (주말 거래 13건은 직전 고시일 환율)
 → 서비스별 수익 계산 → 대시보드
```

- 정답 대조 100건 / 불일치 0건, 해석 실패 0건
- 원화 거래액 = 외화금액 × 적용환율, 총수익 = 수수료 + 외환수익 + 금융수익 항등식 확인
- 현재(시뮬레이션 환율 기준) 총 거래액 38,193,602,951원 · 총 수익 178,418,646원 · 수익률 0.467%

| 서비스 | 건수 | 수익 산식 (가상 정책) |
|---|---:|---|
| 개인 환전 | 25 | 원화 거래액 × 통화별 현찰 스프레드 × (1 − 채널 우대율) |
| 해외송금 | 30 | 금액 구간별 송금수수료 + 전신료 + 원화 거래액 × 1.0% × (1 − 우대율) |
| 기업 외환거래 | 25 | 원화 거래액 × 스프레드 (기업뱅킹 0.25%, 영업점 0.40%) |
| 무역금융 | 20 | max(0.15%, 30,000원) 수수료 + 원화 거래액 × 연 1.5% × 여신일수/365 |

분석 스토리(일본 7~8월 거래 급증, USD 편중, 개인·외국인 모바일 비중 증가, 기업 거래 고액화, 채널별 수수료 차등)는 생성 단계에서 분포로 설계했고, 대시보드의 Insight 문장은 고정 문구가 아니라 현재 필터의 계산 결과로 만들어집니다.

## 실제 ECOS 환율로 교체

1. https://ecos.bok.or.kr/api/ 에서 인증키를 발급받습니다.
2. 패키지 폴더(`bridgeon/`)에서 실행합니다.

```
ECOS_API_KEY=발급키 node tools/fetch_ecos_rates.mjs
node tools/clean_slips.mjs
node tools/build_dashboard.mjs
```

`fetch_ecos_rates.mjs` 는 통계표 731Y001(주요국 통화의 대원화환율)에서 항목명으로 8개 통화를 찾습니다. 찾지 못한 통화가 있으면 파일을 바꾸지 않고 ECOS 항목명 목록을 보여 주므로, 스크립트 상단 `MATCH` 의 검색어를 맞춰 다시 실행하면 됩니다. 이 스크립트는 ECOS 접속이 막힌 환경에서 작성되어 실제 호출로는 아직 시험하지 않았습니다.

## 다시 만들기

```
npm install            # 지도 계산(d3-geo, topojson-client, world-atlas), 국기(flag-icons), Pretendard 글꼴
pip install fonttools brotli   # 글꼴 부분 추출 (없으면 시스템 글꼴로 빌드)
node tools/generate_slips.mjs  # 원본 전표 재생성 (고정 시드, ECOS 환율 파일은 덮어쓰지 않음)
node tools/clean_slips.mjs     # 정제·검증
node tools/build_map.mjs       # 지도 경로 (변경 시에만)
node tools/build_flags.mjs     # 국기 SVG (국가 변경 시에만)
node tools/build_dashboard.mjs # dashboard.html
```

제출할 때는 `bridgeon/` 폴더(`node_modules` 제외)를 `매출전표 파일+분석 대시보드_민승환.zip` 으로 묶으면 원본 전표 파일과 대시보드의 `파일 열기` 상대경로 링크가 함께 유지됩니다.
